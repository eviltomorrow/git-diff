# 01 — 启动与模式 A 变更文件列表

**What to build:** 在 git 仓库中启动即进入 TUI，看到模式 A（工作区↔HEAD）的变更文件列表，可上下移动光标并干净退出。列表是可折叠树形（minishell 文件浏览器风格）：目录为节点、变更文件缩进其下。同时建立 GitFacade 测试缝：命令执行器 trait + fixture 单测。非 git 目录启动即报错退出；空仓库全部文件视为未跟踪。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 在 git 仓库中运行即进入 TUI，默认比较模式为模式 A
- [ ] 左侧变更文件列表为**可折叠树形**：目录节点（📁 + 目录名，增删列留空）、变更文件缩进其下；目录先于文件，组内按字母序
- [ ] 文件行显示：状态字母 + 文件名 + 增删行数
- [ ] 状态颜色：M 黄、A/U 绿、D 红、R 青；光标行蓝底高亮
- [ ] `→` 展开目录、`←` 折叠目录（光标移到父目录行，minishell 行为）；`↑/↓` 移动光标
- [ ] 默认全部展开；`r` 刷新后保持当前展开态
- [ ] 顶部标题显示比较模式描述 + 仓库路径；底部状态栏显示模式、当前文件增删行数与按键提示
- [ ] `q` 与 `Ctrl+C` 均干净退出并恢复终端
- [ ] 非 git 目录启动：错误信息 + 非零退出码
- [ ] 空仓库：模式 A 下所有文件显示为 U（未跟踪）
- [ ] 从任意子目录启动都解析到仓库根，显示全仓库变更
- [ ] GitFacade 以命令执行器 trait 注入，`--numstat`/`--name-status`/`ls-files --others` 输出解析用 fixture 单测覆盖：重命名、未跟踪、二进制、空仓库等边界
- [ ] 重命名检测开启：重命名显示为 R 状态
