# 02 — 模式 A 并排对比视图

**What to build:** 光标在变更文件列表上移动时，右侧对比区即时切换显示该文件的原始侧↔变更侧并排对齐视图：两栏栏头、行号、行级增删高亮（含 `-`/`+` 前缀标记与背景色）、空侧与二进制占位、重命名旧名栏头标注。

**Blocked by:** 01 — 启动与模式 A 变更文件列表

**Status:** ready-for-agent

- [ ] 光标移动即切换右侧对比（无需确认键）
- [ ] 右侧并排两栏：左栏原始侧、右栏变更侧，行与行对齐，`similar` 行级 diff（Equal/Delete/Insert）
- [ ] 两栏均显示行号；改动行整行高亮（增绿删红）
- [ ] **每行改动行前有 `-` / `+` 前缀标记**（窄 gutter 列），一眼区分删除/新增
- [ ] **改动行用背景色高亮**（原始侧删除行红底、变更侧新增行绿底），而非仅前景色
- [ ] 两栏栏头标注各自 ref（如 HEAD / 工作区）
- [ ] 新增/删除/未跟踪文件的空侧显示 "(no original content)" / "(no changed content)" 占位
- [ ] 二进制文件两栏显示 "(binary file)" 占位，不渲染内容
- [ ] 重命名文件正常对比，栏头显示旧文件名
- [ ] 布局：左列表 30% / 右对比区 70% 固定比例
- [ ] GitFacade 经 `git show` 提供两侧内容，行对齐结果经同一条测试缝用 fixture 验证（含 no-newline-at-EOF 等边界）
