# 03 — 对比区滚动与导航

**What to build:** 大文件对比区可滚动与跳转：两栏同步滚动、水平滚动、共享滚动条、hunk 跳转；超大文件降级为无对齐全文视图。`↑/↓` 始终移动文件光标，不做面板焦点切换。

**Blocked by:** 02 — 模式 A 并排对比视图

**Status:** ready-for-agent

- [ ] `Ctrl+↑` / `Ctrl+↓` / `PageUp` / `PageDown` 同步滚动对比区两栏
- [ ] `Ctrl+←` / `Ctrl+→` 水平滚动（两栏同步平移）
- [ ] 对比区右缘共享滚动条，显示剩余内容比例
- [ ] `n` / `N` 跳到下一个 / 上一个改动块（`similar` change group）
- [ ] 超过行数阈值（约 50k 行）的文件降级为无对齐的全文平铺视图
- [ ] `↑/↓` 不参与对比区滚动，永远移动文件光标
