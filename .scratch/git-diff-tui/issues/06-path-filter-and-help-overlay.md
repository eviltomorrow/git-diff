# 06 — 路径过滤与帮助浮层

**What to build:** 变更文件较多时用 `/` 前缀过滤定位文件（状态栏内联输入）；`?` 打开全量快捷键帮助浮层。

**Blocked by:** 01 — 启动与模式 A 变更文件列表

**Status:** ready-for-agent

- [ ] `/` 进入过滤模式，状态栏内联显示 `filter: {输入}`，实时过滤列表
- [ ] 过滤期间**所有目录临时展开**，匹配文件始终可见，不受折叠态影响
- [ ] `Esc` 取消过滤、恢复全列表，并**恢复过滤前的展开/折叠状态**
- [ ] 过滤后光标停留在第一个可见项
- [ ] `?` 打开帮助浮层，列出全部键位与当前模式说明；`Esc` 关闭
- [ ] 状态栏只保留最常用键位提示，完整键位放帮助浮层
